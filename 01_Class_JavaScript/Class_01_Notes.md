## 1. What Is a Language?

A **language** is a system of communication used to share information, ideas, and instructions.

### Examples

- English
- Urdu
- Arabic
- Pashto

**Analogy:** Just as humans use languages to communicate with each other, programmers use programming languages to give instructions to computers.

## 2. What Is a Programming Language?

A **programming language** is a language used to write instructions that a computer can execute.

Programming languages help developers create websites, applications, games, and software.

### Examples of Programming Languages

- JavaScript
- Python
- Java
- C++
- PHP
- C#

### Example

```python
print("Hello, World!")
```

**Output:**

```text
Hello, World!
```

This Python instruction displays a message on the screen.

## 3. What Is JavaScript?

**JavaScript is a high-level programming language used to make websites interactive and dynamic.**

JavaScript allows developers to create features that respond to user actions.

### Uses of JavaScript

- Interactive buttons
- Form validation
- Dropdown menus
- Image sliders
- Real-time updates
- Web applications
- Backend development with Node.js
- Mobile and desktop applications

## 4. Difference Between HTML, CSS, and JavaScript

HTML, CSS, and JavaScript work together to build modern websites.

| Technology | Purpose                           | Analogy                         |
| ---------- | --------------------------------- | ------------------------------- |
| HTML       | Defines the structure and content | Structure of a house            |
| CSS        | Controls appearance and design    | Paint and decoration            |
| JavaScript | Adds behavior and interactivity   | Electrical systems and controls |

**Example:** HTML creates a button, CSS styles the button, and JavaScript makes something happen when the button is clicked.

## 5. My First JavaScript Program

```javascript
console.log("Hello, World!");
```

### Output

```text
Hello, World!
```

### Explanation

- `console` refers to the console where developers can view messages.
- `log()` is a method used to display information in the console.
- `"Hello, World!"` is the text being displayed.
- `console.log()` is commonly used for testing and debugging JavaScript programs.

## 7. JavaScript in a Webpage

The following example demonstrates how JavaScript adds interactivity to a webpage.

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>My First JavaScript Program</title>
  </head>
  <body>
    <h1>Welcome to JavaScript!</h1>

    <button onclick="alert('Hello, World!')">Click Me</button>
  </body>
</html>
```

### How It Works

1. HTML creates the heading and button.
2. The browser displays the webpage.
3. When the user clicks the button, JavaScript displays a popup.
4. The popup displays `Hello, World!`.

## 9. How to Run JavaScript

### Method 1: Using a Web Browser

1. Open Google Chrome.
2. Press `F12` or `Ctrl + Shift + J`.
3. Open the **Console** tab.
4. Write the following code:

```javascript
console.log("I am learning JavaScript!");
```

5. Press Enter.

**Output:**

```text
I am learning JavaScript!
```

### Method 2: Using Visual Studio Code and Node.js

1. Install Visual Studio Code.
2. Install Node.js.
3. Create a file named `index.js`.
4. Write the following code:

```javascript
console.log("My JavaScript Journey Begins!");
```

5. Open the terminal in your project folder.
6. Run the following command:

```bash
node index.js
```

**Output:**

```text
My JavaScript Journey Begins!
```
